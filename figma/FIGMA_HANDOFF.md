# Figma import handoff

The five `frame-*.svg` design assets are editable vector drawings that can be imported into Figma. They are **not** native auto-layout component definitions and are **not** a saved Figma cloud file.

## Steps

1. Create a new Figma Design file titled `Throughline: PLC Planning Partner`.
2. Import the five SVG frames. Place them as distinct 1440×900 concept frames.
3. Recreate the repeated controls as native Figma components: screen shell, step navigation, evidence source cards, coaching prompt, educator input, Decision Thread, agenda rows, stale-data warning, and confirmation controls.
4. Prototype transitions: Evidence → Reasoning → Meeting → Follow-up. Duplicate reasoning and meeting frames for AI-challenge-visible and reapproval-required states.
5. Keep the design-rationale frame alongside the screens, showing why persistent evidence, educator-first reasoning, and bounded pilot scope were selected.

## Design tokens

Navy `#0d293c`, text `#193348`, teal `#086d70`, teal soft `#e9f5f2`, gray background `#f4f7f7`, white `#ffffff`, border `#dce5e7`, blue info `#edf6fa`, amber caution `#fff7e8`. Use consistent spacing and accessible contrast.

The imported screens use fictional classroom data and should be presented as candidate design decisions rather than validated district findings.
