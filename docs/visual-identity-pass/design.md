# Presentation design

Use a white working canvas, ink reading text, cobalt current/selected/action cues and purposeful rules. Replace the sidebar stage rail with four numbered horizontal steps retaining names, statuses and lock explanations. Build the assessment as two aligned rows on a shared 0–120 scale, keeping exact counts and a modest qualified difference. Avoid grids or overlapping pupil representations.

Treat student work as cited response excerpts; let educator decisions and writable directions outrank status chrome. Open the Decision Thread into a ledger with quiet pending states and retained full-text access. Give the kit a crisp document canvas, strong section/title/duration hierarchy and sparse utilities. Match the standalone export through CSS only.

Use self-hosted IBM Plex Sans Regular/SemiBold from the official IBM/plex complete WOFF2 distribution with its OFL. Keep control semantics, validation, dialog focus behavior, event handlers and all model/storage contracts. Existing tests and logic remain unchanged; typography and reduced decoration must not shrink meaningful text or remove supporting material.
