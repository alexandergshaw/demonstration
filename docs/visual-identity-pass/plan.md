# Bounded execution

1. One independent exact-byte planning batch checks this scope, criteria, design and oracle against the actual UX discovery. Related verdicts are truthfully recorded through serialized admissions.
2. Root changes only the admitted presentation paths, documents actual font provenance and checks, then freezes. Independent source review checks protected hashes/export-CSS-only changes; UX inspects the actual visual result and one essential flow, not every historical scenario. Bundle actual findings, repair only demonstrated issues, and recheck the affected candidate.
3. Final independent app-tests and build run once on frozen source. A different reviewer accepts verification/whole-change/local handoff. Freeze public reports, teardown owned QA surfaces, then root commits/pushes once and verifies the actual existing Vercel production release. Release receipts stay in ignored runtime; no future hosted success is recorded in advance.
