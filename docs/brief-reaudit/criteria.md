# Acceptance criteria

- C1: Reflection displays inspectable fictional follow-up context: unknown collection date/task, unverified rubric, unmatched cohort/expected coverage or missingness, and no observed implementation artifact. The fixed result is an illustration independent of the selected action/status; counts alone establish neither comparability nor causality.
- C2: A current recorded reflection exports exact educator text, implementation status and the same context in the text cycle record. Unsaved or invalidated reflection data is excluded. Initial meeting materials exclude the illustrative future outcome. Existing current-plan approval guards and HTML escaping remain effective.
- C3: Existing stored cycles load without schema migration; all model/seed/database/hook contracts and protected tests remain unchanged. Upstream edits continue invalidating approval/reflection.
- C4: Desktop and 320/390px Reflection/context are readable, keyboard usable and draft preserving. Existing dialogs and controls are reused.
- C5: Meaningful new export cases, all existing app tests, and production build pass on the frozen candidate. Independent source/material and bounded browser checks bind exact bytes and preserve instrument limits. Release is separately verified by the parent after local acceptance.
