# Design-pass criteria

- C1 Research and visual hierarchy: actual official Linear/Notion/Panorama comparison evidence is documented without claiming authenticated product use; retain Throughline identity, fictional data and scripted coaching. Compact cycle context, current stage, and one dominant next action replace repeated introductory chrome and excessive containers. Use deliberate type, spacing, surfaces and consistent icons; locally loaded Inter includes its license.
- C2 Evidence-first layout: at1280x720 both key metric values, labels and source date/scope are visible without scrolling. Central working width is at least600px at1280 or a secondary rail is repositioned. Preserve date/scope/noncausal caveats and evidence inspection.
- C3 Accessible feedback: essential normal text contrast is at least4.5:1 and interactive focus contrast at least3:1. Invalid text/agenda/consent/status controls receive target-specific visible errors, aria-invalid and describedby. Error recovery reaches the correct field. Locks are focusable/explained with aria-disabled and cannot dispatch locked transitions. Modal Escape/cancel/save and close restore meaningful focus; destructive confirmation initially favors Cancel.
- C4 Bounded decisions and recovery: long captured decisions have bounded previews with explicit expansion exposing the complete exact text. Preserve visible save/error/lock status. Dirty state installs App-level native refresh protection only while dirty; explicit Reload recovery remains available beside operation errors. Cancellation preserves unsaved input; confirmation restores durable input.
- C5 Responsive robustness: no document overflow or clipped important controls at320,360,390,768,1280px, including open menu/dialog, long cycle names and long authored text. Touch controls target at least44px. Keyboard navigation and primary actions remain usable; test smallest-width textarea/dialog scroll and an appropriate zoom/reflow check.
- C6 Behavioral preservation: complete evidence→interpretation/challenge→focus→meeting/consent→reflection/export flow still works. Reload/cycle switch retains exact input and valid approvals; upstream edits revoke downstream authority but keep drafts; duplicates remain unapproved. All frozen model/database/hook/test/package/tool files retain their baseline hashes unless a concrete accepted repair is separately granted.
- C7 Measured acceptance and delivery: actual browser all-stage, persistence, keyboard/error/lock/disclosure, contrast and responsive observations supplement existing151 app tests and production build. Final app-tests,loop-tests,build run once on the frozen candidate after any repairs. Independent visual/UX review must have no unresolved actionable required-scope finding. Preserve attribution and instrument limits; no exhaustive AT or hosted success claim without evidence. No push; deployment follows clean local acceptance.
