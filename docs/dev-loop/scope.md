# Throughline implementation scope

Implement the supplied Throughline React project in this repository as a local, deployable Vite application. Retain its fictional grade-four PLC planning scenario, navy/teal visual language, source references, and four-stage educator-owned flow. The user owns Vercel deployment. No live model, district data, account integration, paid provider call, remote publication, or deployment is in scope.

Allowed work: app source and tests, package/build configuration, project documentation, and the minimal restored manual loop tool. Historical `.agnostic-loop/backlog-dispatch/` snapshots stay unchanged. New runtime records belong to `.agnostic-loop/throughline/`.

This feature gives an educator a persistent evidence workspace, a traceable Decision Thread, approval gates, an editable meeting plan, and follow-up checks. These are concrete advantages over unstructured chat scrollback.

The host is the current Codex conversation. Worker identities are operator-attested and are recorded with actual subagent handles. Bootstrap consists of extracting the provided archive and restoring the manual engine before engine-backed admissions exist. That setup is explicitly not evidence of completed independent review or automatic-dispatch qualification.
