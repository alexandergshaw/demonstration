# Acceptance criteria

- C1 Evidence stays usable: selected source excerpts remain visible beside interpretation. A keyboard-accessible source reader in interpretation and planning exposes full selected student responses, class table, assessment definitions, source dates/denominators and dated one-class observation with its limits, without stage navigation or draft loss. Closing returns focus meaningfully.
- C2 The promised comparison is possible: clearly fictional lesson/task prompt, expected understanding and simple explanation criteria include a worked sample judgment consistent with the existing evidence. The wording challenge can reach this material. Context lives outside persisted ReferenceData; it is not presented as real district material or proof of student causes.
- C3 A usable meeting artifact: six existing agenda strings accept educator-authored participant activities/facilitation directions. New cycles use a neutral strategy; existing saved wording is preserved. A readable presentable/printable HTML kit derives from the currently approved plan and includes exact interpretation/focus, complete selected evidence and limitations, task/rubric context, all timed directions, action, owner and distinct follow-up checks. Keep the 50-minute agenda and truthful fictional/scripted disclosures.
- C4 Approval and safe output: no kit generation/export before current approval or after upstream invalidation. Exact user text survives safely escaped HTML, including malicious-looking tags/attributes and quotes; output must not execute authored markup. No unapproved reflection is included. Artifact generation does not mutate saved state or approve content.
- C5 Compatibility: existing cycles load without migration or loss of text/approvals. Persisted reference schema, database, seed and workspace hook remain unchanged; all existing model/database tests remain. Existing upstream invalidation, draft preservation, consent, conflict/quota safeguards and approved-export boundaries remain valid.
- C6 Honest rationale: Guide makes the target leader, single-grade pilot assumptions, 20–40-minute preparation target, fixed 50-minute meeting, intended pilot validation and deferred scope discoverable. Assumptions are unvalidated hypotheses. Product/presenter docs match actual React controls and the new kit; Figma is optional, and evidence availability claims match the UI.
- C7 Current-candidate verification: meaningful new kit tests plus all existing tests, production build and final loop suite pass. Independently inspect new source/kit, keyboard/focus, exact authored content, approval revocation, reload compatibility and responsive behavior at 320/390/768/1280px. Distinguish actual HTML/print-CSS inspection from an unperformed native print dialog or paper print. Root's subsequent commit/push/production verification has separate receipts; no remote success is claimed by local gates.
